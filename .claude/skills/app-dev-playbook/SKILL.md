# 単一HTMLアプリの流儀

一般的な作り方は書きません。このプロジェクト固有の決めごとだけです。

## 決めごと
- 依存なしの単一HTMLファイル（CSS/JS内包）。外部CDNは指示がない限り使わない。
- APIキーはコードに直書きせず、画面の入力欄で受け取る。
- コメントは日本語。密度は周囲のコードに合わせる。

## 完成の定義
- 必須の要件をすべて満たしている
- ファイル単体で動く
- 対象ならスマホ表示でも崩れない
- 仮置きやプレースホルダーが残っていない

視覚的な方向性が要るときは `design-notes.md` を読む。
